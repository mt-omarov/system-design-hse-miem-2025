## **1. Обязательные компоненты (MUST)**  

| Компонент               | Обоснование                                                                 | Реализация                          |
|-------------------------|-----------------------------------------------------------------------------|-------------------------------------|
| **Object Storage**      | Хранение документов, шаблонов, медиа. **VK Cloud S3** — управляемое решение с интеграцией CDN и backup. | **VK Cloud S3** (лучше MinIO для продакшена в РФ) |
| **Load Balancer**       | Распределение трафика. | **VK Cloud Load Balancer**         |
| **CDN**                 | Доставка статики. **VK Cloud CDN** — оптимизирован для работы с S3.         | **VK Cloud CDN**                   |
| **Кэш**                 | Ускорение запросов. **Redis** — стандарт, но VK предлагает готовое решение. | **Redis** (self-hosted) или **VK Cloud Managed Redis** (если нет экспертизы) |
| **IdP**                 | Аутентификация. **Keycloak** — гибкость, OIDC/SAML. VK IAM — ограничен.     | **Keycloak** (на своих VM)         |
| **WAF**                 | Защита от атак.  | **VK Cloud WAF**                   |
| **CI/CD**               | Автоматизация деплоя. **GitLab CI** — больше возможностей, чем VK Pipelines.| **GitLab CI** (self-hosted)        |
| **Message Queue**       | Асинхронная обработка. **Kafka** — стандарт для микросервисов.              | **Kafka** (self-hosted)            |
| **Rate Limiter**        | Защита от DDoS. **Redis** + алгоритм Token Bucket.                          | **Redis**                          |

---

## **2. Рекомендуемые компоненты (SHOULD)**  

| Компонент               | Обоснование                                                                 | Реализация                          |
|-------------------------|-----------------------------------------------------------------------------|-------------------------------------|
| **Service Mesh**        | Управление трафиком. **Linkerd** — легче Istio, есть поддержка в РФ.        | **Linkerd**                        |
| **SRE-метрики**         | Контроль SLA. **Grafana** — стандарт. VK Monitoring — менее гибкий.         | **Grafana**                        |
| **Secret Management**   | Хранение секретов. **HashiCorp Vault** — безопаснее VK KMS.                 | **Vault**                          |
| **Database Proxy**      | Шардинг PostgreSQL. **Citus** — лучше PgBouncer.                            | **Citus**                          |

---

### **Вывод**
- **Используем VK Cloud** для:
  - Управляемого S3, Load Balancer, CDN, WAF.
- **Не используем VK Cloud** для:
  - Сложных систем (IdP, CI/CD, Kafka), где важны гибкость и контроль.

**Рекомендация**:
- Стартовать с VK Cloud для S3/LB/CDN.
- Остальное развертывать самостоятельно (если есть экспертиза).
